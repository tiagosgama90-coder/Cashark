# Cashark creator economy & Galaxy Store playbook

## Player loop (addictive but house-favored)

```
Ocean Stardust kills / Roulette
        ↓
     POINTS  ──convert──►  SHARKCOINS  ──convert──►  CASH (€)  ──≥ €10──►  PayPal / etc.
```

| Step | Rate | Why it helps you |
|------|------|------------------|
| Kill / spin | Points drip every action | Session length ↑ · ads ↑ |
| 100 Points → 8 Sharkcoins | Soft sink | Players feel progress without draining Cash |
| 250 Sharkcoins → €0.40 | Strong house edge | **~6 250 SC** to reach €10 |
| Daily roulette Cash cap €0.35 | Soft float guard | Stops lucky streaks emptying the pool |
| Min cashout **€10** | Fraud + float protection | €5 too risky; €20 scares new users |
| Progressive waves | Harder → more continues | Lives / ads / IAP revenue |

## Why €10 (not €5 or €20)

- **€5**: users cash out too early; ad LTV often < payout → you lose  
- **€10**: standard rewards-app gate; enough grind + shop/ads to fund payouts  
- **€20**: safer float but higher drop-off before first withdrawal  

VIP messaging can promise “priority review” at €20 without lowering the €10 gate.

## Premium layer — Pérolas / Pearls

```
Stripe / real money ──► PÉROLAS ──► extra spins · raffle flips · exchange → Sharkcoins
                     └──► Ad-free plans (1d / 7d / 30d / lifetime)
```

- Name follows UI language (Pearls / Pérolas / Perlas / …)
- Soft sink that does **not** inflate Cash directly (house-safe)
- Ad-free plans protect UX for paying users while keeping Stripe revenue

## Creator revenue streams

1. **Rewarded ads** — spins, lives, raffle flips (never trap UX)  
2. **Stripe / Galaxy IAP** — Pearls packs, ad-free, lives, spins, VIP  
3. **House edge** on conversions (you keep the majority of “earned” value)  
4. **Float** — Cash sits until €10; many users never cash out  

## Ocean Stardust (retention engine)

- Free-roam sea arena (swim in a circle around the ocean)  
- Sci-fi shark ship (icon-inspired)  
- Enemy sharks + jellyfish + drones  
- Waves raise speed/HP — more Points per kill, more deaths → monetization
